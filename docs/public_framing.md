# Public Framing Guide

## Single most important rule

Do not let the public-facing description outrun the current build.

## Safest one-sentence description

**MESSINA v25.9 is a bounded public governance-diagnostic surface for chokepoint crisis stress testing under explicit assumptions.**

## Safest short paragraph

**MESSINA v25.9 is a non-predictive public observer surface for comparing how chokepoint crisis governability changes under explicit institutional-friction assumptions. It does not forecast real-world events or assign reliable probabilities. It exposes formulas, configs, artifacts, and a bounded runner so readers can inspect, challenge, and rerun the public governance diagnostics.**
